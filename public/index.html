Instructions for an AI

You are reviewing component heights for ReelKeeper.

Base URL: 
Authentication: Authorization: Bearer YOUR_API_KEY

1. GET /api/height-review/pending
2. For each item, GET its datasheetUrl using the same Authorization header.
3. Read the package mechanical drawing and determine the maximum assembled component height in millimeters.
4. Confirm the drawing applies to the exact manufacturer part number and package variant.
5. POST /api/height-review/{partId}/result with status "approved", heightMm, datasheetPage, confidence, and evidence.
6. Use status "needs-review" with a reason whenever the package variant or dimension is ambiguous. Never guess.
7. Continue until the pending endpoint returns total: 0. Items submitted as "needs-review" leave the default AI queue but remain in ReelKeeper's manual queue.
8. Do not modify inventory quantities or any other component data.

API contract

GET /api/height-review/pending?limit=100
Authorization: Bearer YOUR_API_KEY

Add includeNeedsReview=true only when intentionally rechecking previously ambiguous parts.

GET /api/height-review/{partId}/datasheet
Authorization: Bearer YOUR_API_KEY

POST /api/height-review/{partId}/result
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "status": "approved",
  "heightMm": 1.1,
  "datasheetPage": 7,
  "confidence": "high",
  "evidence": "Dimension A is specified as 0.90-1.10 mm."
}

Uncertain result

{
  "status": "needs-review",
  "reason": "The datasheet contains multiple package variants and the exact variant cannot be confirmed."
}

Only high and medium confidence results can be approved. Anything less certain must be returned for manual review.

Settings & API Docs

General

ReelKeeper stores components, import batches, and movement history in the Docker volume at data/reelkeeper.json.

Part matching

ReelKeeper matches imported rows by LCSC part number first, then manufacturer part number, then compatible passive specs where safe.

Include loose parts in OpenPnP

When off, loose-only components are left out of OpenPnP exports and board assignments. Components that also have machine-ready stock remain available.

Component data

Update all components with current LCSC pricing, product photos, and missing EasyEDA package footprints. New footprints are shown for approval before they are saved.

Component data has not been updated in this session.

Reset ReelKeeper

Remove all components, stock movements, and order import history and return the software to its original empty state.

Use component

Tell ReelKeeper which component was used and how many. Identify it with an LCSC part number, MPN, or internal component id.

curl -X POST http://localhost:3000/api/use \
  -H "Content-Type: application/json" \
  -d '{"lcsc":"C25804","quantity":1}'
